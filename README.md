# BIOTIC TECHNOLOGIES website starter

A responsive Next.js App Router starter for the BIOTIC TECHNOLOGIES corporate website.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
npm start
```

## First customisation tasks
- Replace the temporary Unsplash image URLs in `app/page.tsx` with approved BIOTIC product and project photographs.
- Confirm all product specifications, warranty terms, contact numbers and legal/compliance wording before publication.
- Add real company address, certifications, project references and testimonials only after the company approves them.

## Current scope
This is the first homepage frontend. The contact actions use email and phone links; no enquiry database or admin dashboard has been connected yet.
